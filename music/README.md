Drop your beats here (.mp3 or .wav). Each video picks one at random, mixes it at about -18 dB
under the sound effects, with a 1 second fade in/out, then the whole mix is loudness-matched to
about -15 LUFS (normal TikTok/Reels loudness).

If this folder has no audio files, each video gets an original beat generated in code
(drums, bass and chords; tempo, key and chord progression vary per video), so videos are never silent.

Easiest way to add beats: on GitHub open this `music` folder → Add file → Upload files.
Set the MUSIC_GAIN_DB repo variable to change the beat level (e.g. -12 for louder).
